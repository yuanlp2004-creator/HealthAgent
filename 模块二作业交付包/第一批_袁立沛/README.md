```powershell
backend/.venv/Scripts/python.exe 模块二作业交付包/第一批_袁立沛/run_checks.py
backend/.venv/Scripts/python.exe 模块二作业交付包/第一批_袁立沛/run_checks.py module2
backend/.venv/Scripts/python.exe 模块二作业交付包/第一批_袁立沛/run_checks.py defect-review
backend/.venv/Scripts/python.exe 模块二作业交付包/第一批_袁立沛/run_checks.py regression
```
